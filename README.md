  />
</picture>

</div>

<details>
<summary><strong>🐍 Clique aqui para configurar a Snake Animation</strong></summary>

<br>

No repositório do seu perfil, crie o arquivo:

```text
.github/workflows/snake.yml
```

Depois, cole este código:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"

  workflow_dispatch:

  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write

    runs-on: ubuntu-latest

    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}

          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Publish Snake
        uses: crazy-max/ghaction-github-pages@v4
        with:
          build_dir: dist
          branch: output

        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Depois de salvar, acesse a aba **Actions** do repositório e execute o workflow manualmente pela opção **Run workflow**.

</details>
